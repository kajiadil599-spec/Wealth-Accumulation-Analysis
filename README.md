# Wealth-Accumulation-Analysis
A data analytics project simulating long-term investment compounding strategies using Python and Power BI.
This project simulates a high-frequency compounding investment strategy (7.5% annual rate). It explores the impact of daily reinvestment and monthly capital injections on long-term wealth growth.

Tools & Technologies
Python (Google Colab): Data generation and financial modeling using Pandas.

Power BI: Interactive data visualization and "What-If" scenario modeling.

DAX: Custom measures for portfolio tracking.

Key Insights
Compounding Power: Identified how daily compounding at a 7.5% rate significantly outpaces traditional monthly models.

Financial Planning: Modeled the "Tipping Point" where daily interest earnings exceed the monthly capital injection.
